\subsection*{0.2 Shape and reduction contract}
% Explain (B,1) versus (B,), the possible (B,B) broadcasting error, and 1/B.
The targets are stored with shape $(B,1)$ so they match the logits shape $(B,1)$.
If we combine an array with shape $(B,1)$ and another with shape $(B,)$, NumPy broadcasting can produce an incorrect result with shape $(B,B)$.
Because the loss is the mean over the batch,

        \[
        J = \frac{1}{B}\sum_{i=1}^{B}\ell_i,
        \]

the factor $\frac{1}{B}$ enters backward propagation in

        \[
        \frac{\partial J}{\partial S}
        =
        \frac{\sigma(S)-y}{B}.
        \]

The first bias $b_1$ has shape $(H,)$ and is broadcast across all
$B$ examples when it is added to $XW_1$, which has shape $(B,H)$.

The second bias $b_2$ has shape $(1,)$ and is broadcast across all
$B$ examples when it is added to $A_1W_2$, which has shape $(B,1)$.

The values in $S$ are logits, or raw model outputs. They are not
probabilities. The probability of class 1 is obtained using
$\sigma(S)$.

Since $J$ is the mean loss over the batch, it is a scalar.

\subsection*{1.2 BCE-with-logits derivative}
% Derive dJ/dS = (sigmoid(S)-y)/B with intermediate reasoning.
For one example, let

\[
p = \sigma(s).
\]

The binary cross-entropy loss is

\[
\ell(s,y)
=
-y\log p
-
(1-y)\log(1-p).
\]

First, differentiate with respect to $p$:

\[
\frac{\partial \ell}{\partial p}
=
-\frac{y}{p}
+
\frac{1-y}{1-p}.
\]

Since

\[
p=\sigma(s)=\frac{1}{1+e^{-s}},
\]

the sigmoid derivative is

\[
\frac{\partial p}{\partial s}
=
p(1-p).
\]

Using the chain rule,

\[
\frac{\partial \ell}{\partial s}
=
\frac{\partial \ell}{\partial p}
\frac{\partial p}{\partial s}.
\]

Therefore,

\[
\frac{\partial \ell}{\partial s}
=
\left(
-\frac{y}{p}
+
\frac{1-y}{1-p}
\right)
p(1-p).
\]

Simplifying,

\[
=
-y(1-p)+(1-y)p
\]

\[
=
-y+yp+p-yp
\]

\[
=
p-y.
\]

Since $p=\sigma(s)$,

\[
\frac{\partial \ell}{\partial s}
=
\sigma(s)-y.
\]

The full loss is the mean over the batch,

\[
J=\frac{1}{B}\sum_{i=1}^{B}\ell_i,
\]

so the first backward signal is

\[
\boxed{
\frac{\partial J}{\partial S}
=
\frac{\sigma(S)-y}{B}
}.
\]

\subsection*{1.3 Complete backward chain}
% Derive dW2, db2, dA1, dZ1, dW1, db1, and optionally dX.
% Include shapes and explain batch-axis reductions for bias gradients.
Starting from

\[
dS \equiv \frac{\partial J}{\partial S},
\]

we backpropagate through the output affine layer,

\[
S = A_1 W_2 + b_2.
\]

The output-layer weight gradient is

\[
dW_2
=
A_1^T dS,
\]

with shapes

\[
A_1^T:(H,B),
\qquad
dS:(B,1),
\]

so

\[
dW_2:(H,1).
\]

The output bias gradient is

\[
db_2
=
\sum_{i=1}^{B} dS_i,
\]

so

\[
db_2:(1,).
\]

The gradient passed back to the hidden activations is

\[
dA_1
=
dS W_2^T,
\]

with

\[
dS:(B,1),
\qquad
W_2^T:(1,H),
\]

therefore

\[
dA_1:(B,H).
\]

Next, since

\[
A_1=\operatorname{ReLU}(Z_1),
\]

the ReLU derivative gives

\[
dZ_1
=
dA_1 \odot \mathbf{1}(Z_1>0),
\]

so

\[
dZ_1:(B,H).
\]

For the first affine layer,

\[
Z_1=XW_1+b_1.
\]

The first-layer weight gradient is

\[
dW_1
=
X^T dZ_1,
\]

with

\[
X^T:(D,B),
\qquad
dZ_1:(B,H),
\]

so

\[
dW_1:(D,H).
\]

The first-layer bias gradient is

\[
db_1
=
\sum_{i=1}^{B} dZ_{1,i},
\]

therefore

\[
db_1:(H,).
\]

Bias gradients reduce over the batch axis because the same bias parameter is shared by all examples in the batch. The contributions from all examples are summed, while the remaining dimensions match the original bias parameter shapes.
